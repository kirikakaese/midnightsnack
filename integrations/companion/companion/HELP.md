## DECK

Controls [DECK](https://github.com/kirikakaese/midnightsnack), the free presentation host.

### Setup

1. In DECK open the **Control** tab, create an **API key** (role *Operator*) and copy it.
2. If Companion runs on another computer, untick **Only from this computer** below the API keys.
3. Add this connection in Companion and enter the host's address, port (default `4747`) and the key.

### Actions

Go, next/previous slide, next/previous cue, go to cue *n* (and slide), blackout / freeze / logo
(toggle, on, off), panic, overlays, clear drawing, media play/pause/restart, slide timer and
countdown, message to stage.

### Feedbacks

Blackout / freeze / logo active, cue *n* is live, overlay shown, countdown in overtime.

### Variables

`show_title`, `cue_name`, `cue_number`, `slide`, `slide_count`, `slide_of`, `next_name`,
`show_timer`, `slide_timer`, `countdown`, `countdown_label`, `stage_message`.
