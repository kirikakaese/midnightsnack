# Ideas and proposals

Features that are not part of the roadmap are collected here first. Open an issue to discuss one
before implementing it.

- **Render visible PDF annotations** — per-cue option to draw ink/stamp annotations while still
  hiding sticky notes.
- **pdf.js fallback** — render PDFs in the webview when PDFium is unavailable on a platform.
- **Keymap editor** — edit keyboard/clicker bindings in the UI instead of `host-settings.json`.
- **Slide thumbnails in the cue list** — show the first slide of each cue.
- **More transitions** — slide, wipe, dissolve through black.
- **Audio beds** — keep an audio cue playing underneath following visual cues.
- **Native media backend** — libmpv rendering into the output window for wider codec support.
