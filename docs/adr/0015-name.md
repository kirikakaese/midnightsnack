# 0015. The name DECK

- **Status:** accepted
- **Date:** 2026-10-10

## Context

The project was developed as *midnightsnack*, a codename. 1.0 needs a name that says what the
app is for and fits next to the author's other tools (short, upper-case acronyms).

## Decision

The app is called **DECK** — *Display Engine & Cue Keeper*: a deck of slides, and the
operator's desk.

- Renamed: everything people see (app and window names, the phone page, installers, the
  binary `deck`, the relay binary and image `deck-relay`, the Companion module's name, the
  self-signed certificate, the MIDI port, docs) and the app identifier
  `io.github.kirikakaese.deck`. On first start, data in the folders of the old identifier is
  moved to the new ones, so settings, paired devices and the autosave survive.
- Kept as *midnightsnack*: show files (`.msnack`, as a nod to the codename), the repository,
  crate and package names, and everything on the wire or stored on phones — the Noise
  prologue and relay host-id context, the mDNS service type, OSC addresses
  (`/midnightsnack/…`), the Companion module id, `MIDNIGHTSNACK_*` environment variables and
  browser storage keys. Changing those would break pairings, relays, control setups and
  integrations for no visible gain.

## Consequences

- Phones and relays from 0.x keep working with 1.0.
- Developers still see `midnightsnack` in code; the README explains why.
