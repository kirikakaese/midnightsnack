# Several screens

A show has one or more **outputs**. Each output is a window on its own display: the main
projector, a screen in a second room, or a confidence monitor facing the speaker. Outputs are
part of the show; which physical display each one uses is remembered on this computer, so the
same show works on a different laptop.

## Adding and setting up outputs

Open the **Outputs** tab. Every show starts with **Main**. Click **+ Output** to add more, then
for each one set:

| Setting           | Meaning                                                                    |
| ----------------- | -------------------------------------------------------------------------- |
| **Name**          | Shown in the cue inspector and on test patterns                            |
| **Shows**         | **Program (audience)** — slides and media; **Stage display (presenter)** — current and next slide, notes, timers and your messages |
| **Scaling**       | How content with another aspect ratio is fitted: **Fit** (black bars), **Fill** (crop), **Stretch** |
| **Safe margin**   | Shrinks content by this percentage on every side (projectors that cut off the edges) |
| **Show overlays** | Lower thirds, clock, ticker and logo bug on this output                    |
| **Display**       | The display the output covers; **Windowed** opens a normal window instead  |

Then click **Open output**. **Move output** sends an open output to another display, **Close
output** closes the window (the output stays in the show), **Remove output** deletes it from the
show. Open outputs reopen on their display the next time you start DECK.

## Showing different cues on different screens

By default a cue goes to every program output. To send a cue only to some of them, select it,
open the **Cue** tab and untick **Show on all outputs** under **Outputs**, then choose the
outputs. Outputs that are not selected keep showing what they showed before. For example, keep
the sponsor loop on the foyer screen while the main room continues with the talk: give every
talk cue only the **Main** target.

The cue list marks cues with a target list ("1 output"). Blackout, freeze and logo affect all
outputs.

## When a display is unplugged

If the display of an open output disappears (a loose cable, a projector switched off), the
output window is hidden — it never jumps onto your own screen — and the **Outputs** tab warns
which output lost its display. The show keeps running. When the display comes back, the output
returns to it on its own.

## Test patterns

**Grid** and **Color bars** in the **Outputs** tab replace the content on every program output
with a test pattern that shows the output's name and resolution, for aligning and focusing
projectors. **Off** returns to the show. The program monitor shows the pattern too, so you can
see it is on.
